# Strawberry Linux Package Repository

Official package repository for Strawberry Linux and the Berry package manager.

## Repository format

The repository index is published at `index.json`. Package archives are stored at the repository root and are referenced by filename and SHA-256 checksum in the index.

## Status

The repository is being set up. Package installation through Berry will be enabled after archive validation, safe extraction, and package ownership tracking are implemented.
